### 1.1 Состав колонок бланка

**Форма 2П (экранная/печатная)** — колонки в справке перечислены при описании кнопки «Создать» (разд. 6.1, стр. 1029–1032) и формы 2П комплексная (разд. 7): столбец 2 — «Характеристика объекта», столбец 3 — «Номер» (номера частей, глав, таблиц, параграфов и пунктов), столбец 4 — «Расчет стоимости» (символьная и числовая формула), далее столбцы стоимости. Полный нумерованный список колонок формы 2П отдельным перечнем **в справке не описано** — он выводится из настроек отображения (разд. 2.1) и из состава 2П комплексной.

**Форма 2П комплексная** — «В форме сметы 7 столбцов» (разд. 7, стр. 1078), фактически перечислено восемь:

| № | Наименование столбца |
|---|---|
| 1 | «№ п/п» |
| 2 | «Характеристика предприятия, здания, сооружения или виды работ» (внутри — блок «Коэффициенты» и блок «Разделы проектной документации» = таблица относительной стоимости, ТОС) |
| 3 | «Номер частей, глав, таблиц, процентов, параграфов и пунктов указаний к разделу СБЦ» |
| 4 | «Расчет стоимости» — символьная и числовая формулы, «без умножения на Кст» |
| 5 | «Стоимость, стадия ПД» |
| 6 | «Стоимость, стадия РД» |
| 7 | «Всего» |
| 8 | «Примечания» (редактируется вручную) |

Таблица ТОС в 2П комплексной: перечень всех РПД всех стадий, нормативные значения относительной стоимости по стадиям, фактические значения, «% выполнения = фактическое значение относительной стоимости РПД / нормативную относительную стоимость РПД» (изначально 100 %), последняя строка — «Коб П+Р (КР)». Двойной клик по названию РПД либо по ячейке открывает окна начисления коэффициентов (разд. 7, стр. 1079–1083).
**Важно для реализации:** «Печать 2П комплексная и 2П комплексная расчет возможна только в редакторе MS Excel» (разд. 7, стр. 1084).

**Форма 4П:** «Экранная форма сметы состоит из 9 столбцов»; «Перенос расценок в смету из базы неактивен, строки сметы создаются вручную»; «Столбцы 2-8 формы редактируемые»; итоговая строка — «Итого по сметному расчету»; в сводную смету добавляется по выбранной стадии (разд. 11, стр. 1094–1097). Наименования 9 столбцов текстом **в справке не описано** (приведены только на рисунке).

**Форма «Расчёт цены работ»:** «Таблица формы по умолчанию состоит из 12 столбцов», число столбцов зависит от количества поставщиков; кнопка «Поставщики» — по умолчанию 3, максимум 15 (разд. 15, стр. 1107–1110).

### 1.2 Отличия расчёта по формам

- **2П / 2П 707/пр** — расчёт от натуральных показателей: `Ц = (А + В * Хзад) * Ктек * Кст` (разд. 5.1).
- **2П комплексная** — Кст в столбце 4 не применяется; стоимость ПД и РД считается отдельными столбцами через ТОС; выбор стадии неактивен: «Для этой формы неактивен выбор стадии» (разд. 7, стр. 1077).
- **3П** — расчёт от трудозатрат исполнителей; кнопка «Создать/работу» открывает окно «Создание работы» с полями «Наименование работы», чекбоксами исполнителей, количеством исполнителей, чел.-дни / чел.-часы; исполнители берутся из справочника «Должности» (разд. 9, стр. 1087–1089).
- **3П для РЖД** — переносятся исполнители и индекс уровня зарплаты; вводятся фактическое время работы и численность; по Тп (плановая продолжительность) рассчитывается Ккв(уч); редактируются ЗПсрм баз, Д, Кз, Р, Кр, Кпер, Кс (Кпер из справочника «Индексы»; Кс — коэффициент снижения стоимости работ); по формулам в смете рассчитываются ЗПср(баз), Ссед, Сбаз, Спр(баз) → Спр (разд. 10, стр. 1091–1093).
- **МРР-9.1.02-18** — Ккв определяется по Тп; редактируются ЗПср.м. 2000, Д, Кз, Р, Кпер; по формулам считаются ЗПср.дн., Вср.дн., Цб; индексы зарплаты — «Глава 2, таблица 2.1». Неучтённая строка выводится «бледным серым шрифтом», «не учитывается в расчетах» и в форму отчётности не выводится (разд. 12, стр. 1098–1100).
- **3П полные расходы / 3П НМЦ** — кнопка «Создать» → «Создание/Сотрудника/Сотрудника из справочника/Командировку/Текстовую строку» (разд. 13–14, стр. 1101–1106).
- **«Расчёт цены работ»** — Вариант 1: «Утверждаемая цена за единицу измерения рассчитывается как произведение Цены работ в предшествующем периоде на Индекс-дефлятор»; Вариант 2: «Среднерыночная цена - это среднее арифметическое по ценам всех поставщиков», умноженное на индекс-дефлятор (разд. 15, стр. 1108–1109).

## 4. Типы расчёта расценок (разд. 5)

### 4.0 Общий механизм переноса расценки (разд. 5, стр. 950–951)

Расценка переносится мышью или кнопкой на панели БД; открывается окно «Добавление расценки», состав полей зависит от типа расценки; выводится код расценки и уровень цен. «Основной показатель (Х заданный) можно ввести вручную или с помощью кнопки «Формула для Х»». Для групповых расценок (включающих несколько подрасценок) окно дополнено блоком «Параметры расценки»; в поле «Мощность» значение вводится вручную или «Формулой для Мощности», и «в зависимости от введенного значения автоматически подбирается один из параметров, соответственно меняются величины А, В, Х минимальный, Х максимальный».

### 4.1 Тип расчёта «от натуральных показателей» (разд. 5.1, стр. 951–953)

Основная формула:

```
Ц = (А + В * Хзад) * Ктек * Кст
```

- `А`, `В` — постоянные величины базовой цены из расценки;
- `Хзад` — заданный основной показатель (в блоке «Натуральные показатели объекта» выводятся Хмин и Хмакс);
- `Ктек` — коэффициент перехода в текущие цены; `Кст` — коэффициент стадийности.

Если величина `В` отсутствует либо единица измерения не совпадает:

```
Ц = А * Ктек * Кст
```

**Экстраполяция:**

```
Хзад < Хмин:   Ц = (А + В * (0,4 * Хмин + 0,6 * Хзад)) * Ктек * Кст
Хзад > Хмакс:  Ц = (А + В * (0,4 * Хмакс + 0,6 * Хзад)) * Ктек * Кст
```

Если Хзад более чем в 2 раза меньше Хмин, выполняется «Расчет для минимального Х зад = Х мин / 2», после чего применяется понижающий коэффициент `Кпон = Х зад факт / Х зад расч`; минимальное значение Кпон задаётся в «Настройки / Общие настройки / Правила». При запрете экстраполяции расчёт ведётся по `А + В * Х`.

### 4.2 Интерполяция (разд. 5.2, стр. 954–957)

```
Хзад = Х:              Ц = A * Ктек * Кст
Хn-1 < Х < Хn:         Ц = (An-1 + ((An - An-1) / (Хn-1 - Хn)) * (Хзад - Хn-1)) * Ктек * Кст
Хзад < Х1:             Ц = (A1 - ((A2 - A1) / (Х2 - Х1)) * (Х1 - Хзад) * 0,6) * Ктек * Кст
Хзад > Хn:             Ц = (An + ((An - An-1) / (Хn - Хn-1)) * (Хзад - Хn) * 0,6) * Ктек * Кст
```

Ряд значений `Хi`/`Ai` выводится во вкладке «Дополнительно» окна добавления расценки.

### 4.4 Метод «от общей стоимости строительства» (разд. 5.4)

**5.4.1 (сборники 2001 г., стр. 995–998).** Вводятся Стек, Ксмр (из справочника «Индексы СМР»), К2000–2001 → рассчитывается Сбаз. Вкладка «По составляющим» — строительство, монтаж, оборудование, прочие. Вкладка «Дополнительно» — таблица значений α.

```
Ц = C 2001 * α / 100 * Ктек * Кст

интерполяция:
Ц = C 2001 * (αпред - ((αпред - αслед) / (Сслед - Спред)) * (С 2001 - Спред)) / 100 * Ктек * Кст
```

За крайними табличными значениями α принимается по крайним строкам «(без экстраполяции в сторону уменьшения или увеличения)».

**5.4.2 (сборники 1994–1998 гг.: ЦБП, Энергетика, Машиностроение; цены 1991 г., стр. 999).** Ранее применялась `Ц = (Стек*α)/100*Кст` (Ктек не применялся); теперь:

```
Ц = С 2001 * α / 100 * Ктек * Кст
С 2001 = Стек / Ксмр 2001 * 1,25
С 1991 = Стек / Ксмр 1991
```

Ксмр 1991 «последний раз» публиковался в 1 кв. 2010 г., поэтому применяется множитель «Ксмр 1кв2010 / текущий Ксмр».

### 4.5 Расчёты 5.5.1–5.5.10

**5.5.1 РНиП (стр. 1000–1002).** Тчд — трудозатраты на единицу измерения в чел.-дн.; Хзад — основной показатель; Счд — «усредненная стоимость чел.дн., в руб». «Коэффициент перехода в текущие цены (если Счд вводится текущая) и стадии проектирования для данного сборника отсутствуют».

```

Экстраполяция:     Хзад < Хмин:  Ц = Счд*Тчд*(0,4*Xмин + 0,6*Xзад)
                   Хзад > Хмакс: Ц = Счд*Тчд*(0,4*Xмакс + 0,6*Xзад)
Интерполяция:      Хзад = Х:            Ц = Счд*Тчд
                   Хпред < Хзад < Хслед: Ц = Счд*(Тчд(пред) + ((Тчд(след) – Тчд(пред))/(Хслед – Хпред))*(Хзад — Хпред))
                   Хзад < Х1:           Ц = Счд*(Тчд1 – ((Тчд2–Тчд1)/(Х2 — Х1))*(Х1–Хзад)*0,6)
                   Хзад > ХN:           Ц = Счд*(ТчдN + (ТчдN–Тчд(N–1))/(XN–X(N–1))*(Xзад–ХN)*0,6)
```

«Различия печатной формы 2П для РНиП от формы 2П только в наличие дополнительного столбца «Количество»».

**5.5.2 Сборники укрупнённых цен без стадий (прейскуранты, ценники, укрупнённые показатели; стр. 1003).** Расчёт: «Цена» * «Количество единиц измерения в объекте» * «Количество объектов»; «отсутствуют стадии проектирования и разделы проектной документации». В смете у таких расценок нет информации о стадиях и РПД.

**5.5.3 ОНЗТ (стр. 1004–1006).** Вводятся количества единиц измерения для показателя «А» (Х1) и «В» (Х2).

```
Ц = (А*Х1 + В*Х2) * Ктек
```

Ктек берётся из раздела «Индексы для ОНЗТ» (отличается от Ктек проектных и изыскательских работ). Повышающие коэффициенты на 2003 г. (Письмо Роскомземкадастра от 10.01.2003 № НК/25): Европейская часть РФ — 4,22; Западная и Восточная Сибирь — 4,42; Дальний Восток — 4,61; Крайний Север — 4,80. «Для определения коэффициента перехода на текущий год… необходимо умножить коэффициент перехода 2003 года и коэффициенты–дефляторы всех предыдущих годов». Вместо РПД действует «Типовое соотношение расходов», всегда из 2 пунктов: «1. Непосредственное изготовление продукции; 2. Обеспечение труда и управление работами». Коэффициенты могут начисляться отдельно на цену А, на цену В, либо быть общими; «Значение многих коэффициентов рассчитывается по формуле в зависимости от введенного в графу «n» значения».

**5.5.4 «Объекты энергетики ОАО РАО «ЕЭС России»» (стр. 1007–1009).** Стоимость определяется от общей стоимости строительства в ценах 2001 г. (С); методы выбора: «Сстр2000г от общей стоимости», «Сстр2000г по составляющим», «Сстр тек от общей стоимости», «Сстр тек по составляющим» (составляющие: строительство, монтаж, оборудование, прочие). Интерполяция:  Ц = (Aслед - (Aслед - Апред) / (Сслед - Спред) * (Сслед - C 2001)) * Ктек * Кст


## 5. Коэффициенты (разд. 6.2, стр. 1038–1045)

Открытие: кнопка «Коэффициенты» → «Для выбранных расценок» / «Для всех расценок».

### 5.1 Структура таблицы коэффициентов — 8 столбцов

| Столбец | Назначение |
|---|---|
| чекбокс | включение коэффициента в расчёт |
| Наименование | название коэффициента |
| Обоснование | ссылка на пункт СБЦ/МРР/письмо |
| Значение | числовое значение |
| Тип | выпадающий список: Ценообразующий, Усложняющий, Составной (в начислениях также Делитель) |
| Мин | рекомендуемый минимум, не редактируется |
| Макс | рекомендуемый максимум, не редактируется |
| Количество | кратность многократного применения коэффициента |

### 5.2 Порядок применения по типам (дословно)

> «Если коэффициенты имеют тип «Ценообразующий», то при начислении нескольких коэффициентов их значения перемножаются. Если коэффициенты имеют тип «Усложняющий», то их дробные части складываются с единицей. Если коэффициенты имеют тип «Составной», то они складываются.»

Дополнительное правило группировки для расчётов обследования/ЭПБ (разд. 5.3.12, стр. 987): «Если внутри одной группы коэффициенты с типом «Усложняющий», то складываются с единицей дробные части, разные группы между собой перемножаются… коэффициент без метки считаются отдельной группой».

Формализация:
- ценообразующие: `K = Π ki`;
- усложняющие в одной группе: `K = 1 + Σ (ki − 1)`;
- составные: `K = Σ ki`;
- группы усложняющих между собой перемножаются;
- делитель (только в начислениях): операция «Разделить на коэффициент».

### 5.3 Варианты начисления и цветовая индикация

| Вариант | Цвет | Особенности |
|---|---|---|
| «Начислить на раздел/подраздел» | красный | коэффициент применяется к итогу раздела |
| «Начислить на расценку, учитывая не все разделы и подразделы» | зелёный | `Коб = ст.3 / ст.2`; поле «Базовое значение коэф-та»; кнопка «Пересчет % сметной документации»; чекбокс пересчёта при редактировании РПД |
| «Начислить на удельную стоимость» | фиолетовый (в окне «Коэффициенты») / синий (во вкладке «Удельная стоимость») | применяется к элементу состава удельной стоимости |

### 5.4 Ограничение коэффициентов к МРР

Настройка включается в окне создания/редактирования сметы, вкладка «Дополнительно» («Расчет коэффициентов к МРР», результат «не должно превышать 2.0»). В таблице коэффициентов появляется столбец «Ккор МРР» с чекбоксами (по умолчанию заполняется из БД МРР / «Действующие»); исключение — МРР-5.4-16_0-2-1.

> «Важно: тип корректирующих коэффициентов для МРР должен быть Ценообразующий»
> «Если ПКi>2, то в символьной формуле расчета выводится множитель ПКi, а в числовой формуле выводится множитель со значением 2»

Для одного коэффициента со значением > 2 «после значения выводится «>2»».

### 5.5 Настройки учёта и печати

ПКМ в смете → «Учитывать в расчетах» с тремя состояниями: «учитывать» / «не учитывать» / «не учитывать, но печатать» (разд. 6.1, стр. 1035). «Вывод обоснования»: Полное / Сокращённое / По настройкам. Флаги вывода значений, наименования, обоснования и типа коэффициентов задаются в шаблоне (разд. 2.1, блок «Коэффициенты»).

**Символьная и числовая формула.** В шаблоне сметы отдельно включаются «Символьная формула, кроме формулы изысканий», «Символьная формула для изысканий» и «Числовой расчет» (разд. 2.1). То есть в столбце «Расчет стоимости» может присутствовать до двух представлений одной формулы — символьное (с буквенными обозначениями A, B, Хзад, Ктек, Кст, ПКi) и числовое (с подставленными значениями). Для канона это два разных поля: `Position.formula_raw` и `Position.formula_numeric`.

## 6. РПД (6.3), состав сооружений (6.4), удельная стоимость (6.5), начисления (6.6)

### 6.1 Разделы проектной документации — РПД (разд. 6.3, стр. 1046–1053)

Вкладка «Разделы ПД» в окне «Коэффициенты расценки» содержит: стадию с её Кст и перечень всех РПД с процентами относительной стоимости.

Кнопки: «Добавить раздел/подраздел», «Удалить», «Сохранить в Типовые РПД», «Пересчет Кст», «Дублировать на другую стадию», перемещение строк.

Механизм «Пересчет %»:

| Вариант | Правило |
|---|---|
| «% СД» | по Письму ЦИП от 23.01.2017 № 17-03/4 |
| «до суммы 100%» | `новый % = старый % * 100 / старую сумму процентов` |
| «до суммы 100% без изменения выделенного» | `новый % = (старый %) * (100 – выделенный %) / (старую сумму – выделенный %)` |
| «Восстановить» | возврат к нормативным значениям |

Пересчитанные значения выделяются розовым цветом. В шаблоне сметы отдельно управляется вывод РПД, исключённых РПД, начисленных на РПД коэффициентов, расчёта общего процента РПД, сумм по РПД и сокращений наименований (разд. 2.1).

ПКМ в смете: «Возврат к базовым РПД для выбранных расценок», «Показать/скрыть РПД» (разд. 6.1, стр. 1034–1035). Схема пересчёта РПД переносится во все новые объекты/сметы (вкладка «Пересчет РПД», разд. 2.1).

**Влияние на итоги:** процент РПД определяет распределение стоимости расценки по разделам ПД; исключение РПД уменьшает учитываемый процент, и в смете печатается расчёт общего процента. Если РПД отсутствуют, при включённой настройке выводится «Полный комплекс работ 100 %».

### 6.2 Состав сооружений (разд. 6.4, стр. 1054–1057)

Отдельная вкладка окна «Коэффициенты расценки». Кнопки: добавить, удалить, сохранить, дублировать, переместить. Переключатель дублирования изменений на другую стадию — по умолчанию отключён. Есть «Добавление из типовых сооружений» с поиском. ПКМ: «Удалить», «Коэффициенты». Вывод возможен с одной или двумя стадиями. В шаблоне управляется вывод: состав сооружений, только при наличии исключённых, процент по составу, расчёт общего процента, исключённые сооружения, сокращённое наименование (разд. 2.1).

### 6.3 Удельная стоимость (разд. 6.5, стр. 1058–1061)

Вкладка присутствует только у расценок, «где состав удельной стоимости заложен в БД» (пример: СБЦ «Объекты энергетики. Электросетевые объекты», 2016). При добавлении/удалении/редактировании элемента пересчитывается процент.

> «В строке с названием стадии выводится Куд ст, так же значение Куд ст участвует в формуле расчета вместо Кст»
> «В основной строке расценки в столбце 4 в числовой формуле значение Кудст учитывает начисленные коэффициенты»

Коэффициенты на удельную стоимость выводятся синим цветом после соответствующей строки, а в окне «Коэффициенты» — фиолетовым; их можно дополнительно начислить на всю расценку. В скобках после значения выводятся пункты удельных стоимостей.

### 6.4 Начисления (разд. 6.6, стр. 1062–1076)

Окно начислений повторяет структуру сметы: разделы, «Итого по разделу», «Всего по разделу», «Итого по смете», «Всего по смете». Раздел начислений (создаётся чекбоксом «Раздел начислений») не имеет строки «Итого по разделу».

**Столбцы окна начислений:**

| № | Столбец | Примечание |
|---|---|---|
| 1 | № по смете | |
| 2 | Наименование | |
| 3 | Обоснование | |
| 4 | Операция | см. ниже |
| 5 | Тип | Ценообразующий / Усложняющий / Составной / **Делитель** |
| 6 | От чего | база начисления |
| 7 | Значение | |
| 8 | Стоимость | не редактируется |

**Операции:** «Коэффициент»; «Группа коэффициентов»; «Процент»; «Разделить на коэффициент»; «Процент и коэффициент» (поля `k=` и `р=`); «Формула» (переменные обозначаются английскими буквами, дополнительный расход добавляется кнопкой `*S`; «в смете переменные заменяются на номера пунктов», к сумме добавляется «руб.»/«тыс.руб»); «Доп. Расходы» (тип: проектные или изыскательские, поле «От чего» неактивно); «Сумма».

**Значения «От чего»:** «От итого / всего по разделу» (с выпадающим списком разделов); «Пункт сметы»; «Пункт сметы с учетом начислений» (пункты перечисляются через запятую или диапазоном через тире); «Сумма» — «от последнего «Итого» до предыдущего пункта».

Начисления, размещённые после «Всего по смете», «не учитываются в расчете и являются информационными» и отличаются «пустым» значком.

Подменю «Добавить»: «НДС 20 %» (можно 18 %), «Итого», «Начисление – Итого», «Строка для расчета».

Кнопки: «Коэффициент на начисление» (доступна для операций Коэффициент / Процент / Разделить на коэффициент / Процент и коэффициент); «Удалить»; «Переместить»; «Столбцы»; «Сохранить в мои начисления»; «Тендерный коэффициент» (вводится конечная сумма, Ктендер рассчитывается автоматически); «Командировочные расходы»; «Среднеарифметический индекс» — `(I1 + … + In) / n`.

### 6.5 Работа в смете и панель инструментов (разд. 6.1, стр. 1029–1037)

- **«Создать» → «Раздел»:** поле «Наименование» + выпадающий список ранее созданных наименований; чекбокс «Раздел начислений» (раздел содержит только начисления).
- **«Создать» → «Строку»:** «Характеристика объекта» → столбец 2; «Номер» → столбец 3; «Расчет стоимости» → столбец 4; «Стоимость» — автоматически либо вручную при включённом чекбоксе «Редактировать».

## 7. Сводные сметы (разд. 17, стр. 1115–1123) и связь локальных со сводной

**Создание:** выделить объект (его договор или смету) → главное меню «Общее» → «Создать сводную смету на ПИР». «Для каждого объекта - свои сводные сметные расчеты». В окне создания задаются номер и наименование сметы, выбирается шаблон.

**Вкладка «Спец»:** процент НДС (18 % или 20 %) «для расчета в графах сводной сметы и для вывода на печать в отраслевой форме»; «сметы включать без НДС» — регулирует добавление смет «учитывая/не учитывая НДС» начисленный в них; «НДС из смет в концовке» — «все локальные и сводные сметы добавляются в сводную без НДС. Также автоматически добавляется начисление НДС, при расчете которого учитываются только те сметы, в которые был добавлен НДС. Это начисление выделяется зеленым цветом и не удаляется, пока включена настройка». Чекбоксы взаимоисключающие.

**Панель инструментов сводной:** «Выбор смет»; создание разделов/подразделов/текстовых и др. строк; удаление; выбор столбцов; начисления («Начисления можно добавить на итоги по разделам и по всей сводной смете. Работа в начислениях организована так же, как для локальной сметы (в том числе есть возможность создания информационных начислений после Всего по смете)»); сохранение структуры с начислениями как шаблона; «Пересчитать» («позволяет пересчитать сводную смету в соответствии с последними изменениями в сметах, сходящих в ее состав»); «Этапы»; отмена/повтор выбора смет; «Печать»; перемещение строк вверх/вниз; «скрывает/показывает пустые разделы сметы».

**Распределение смет по разделам** — настройка выбирается только при создании сводной сметы.

## 8. Общие настройки смет ПИР (разд. 21) и автоиндексация (разд. 20)

### 8.1 Общие настройки смет ПИР (стр. 1140–1143)

Вызов — ПКМ на объекте или папке. Серая галочка означает частично включённую настройку (часть смет). Чекбоксы:
- **«Смета от»** — единая дата во все сметы + вывод её на печать;
- **«Объект»** — обновление названия объекта во всех сметах + вывод на печать;
- настройки округления применяются ко всем сметам объекта;
- **«Подписи»** — по умолчанию пусто; выбор группы подписей заменяет группу во всех сметах, выбор пустой группы очищает подписи; «Подписи отображаются только общие для всех смет».

ПКМ на смете или группе смет → «Применить настройки объекта» с вариантами «Да» и «Да, кроме наименования сметы» (второй вариант не затрагивает поле «Наименование предприятия, здания, сооружения, стадии проектирования, этапа, вида проектных или изыскательских работ»).

### 8.2 Автоиндексация смет ПИР (стр. 1137–1139)

Вызов: меню «Расчеты» → «Автоиндексация смет ПИР», либо ПКМ на папке/объекте/договоре. Поддерживаются **только формы 2П**: 2П, 2П изыскания, 2П изыскания доп, 2П комплексная, 2П комплексная расчёт. Задаются регион, год, квартал. Отдельно поддерживаются «РЖД прогнозные индексы». Есть «Фильтр индексированных смет».

### 8.3 План по локальным сметам ПИР (разд. 22, стр. 1144–1157) и импорт задач (разд. 23)

- «Создать план» доступно на уровне папки, подпапки, объекта. Фильтр «Показать»: сметы, планы, калькуляции.
- Параметр «Доля ЗП в сметах ПИР»: «заработная плата рассчитывается по формуле Всего * Долю ЗП. По умолчанию значение равно 0.6839».
- Подразделы: 22.1 (общий план), 22.2 план по изысканиям — помечен в справке как временно недоступный, 22.3 АСУТП, 22.4 2П комплексная, 22.5 ПКР+АСУТП, 22.6 3П, 22.7 окно «Задача».
- Разд. 23 «Импорт задач из дерева объектов» (стр. 1158–1159) — импорт задач планирования **из внутреннего дерева объектов Адепта**, а не из внешних файлов.

### 8.4 Приложение НЦС/НЦКР (стр. 1160+)

Отдельные базы НЦС и НЦКР с собственным поиском (п. 1, 1.2), создание расчёта НЦС (2.1), расчёт (2.2), добавление расценок с интерполяцией (2.3), коэффициенты НЦС (2.4), НЦКР (3). К сметам ПИР напрямую не относится; в канон PIR-IR не отображается.

### 9.1 Прямые ответы на контрольные вопросы

| Вопрос | Ответ по справке |
|---|---|
| Есть ли в модуле ПРОЕКТ **импорт из Excel**? | **Нет, кроме одного случая** — справочник «Должности»: «Данные можно загрузить из специального файла Excel» (разд. 3.11, стр. 939). Также «Виды деятельности» и «Перечень работ» можно «загрузить данные из файла» (разд. 3.3, 3.4, стр. 922–925), но формат файла **в справке не описано**. Импорта сметных таблиц ПИР из Excel в справке не описано. |
| Есть ли **импорт XML ГРАНД-Сметы**? | **В модуле ПРОЕКТ — не описано.** Упоминания форматов обмена (в т.ч. АРПС и XML) присутствуют только в описании модуля СМЕТА (стр. 331–336 справки). |
| Есть ли **вставка таблицы из буфера обмена**? | В модуле ПРОЕКТ есть только **внутренний** буфер программы: ПКМ → «Копировать в буфер» / «Вставить из буфера» (разд. 6.1, стр. 1034). Семантика: «Скопированные разделы будут вставлены в конце сметы со всеми расценками и начислениями на раздел»; «Скопированная из другой сметы расценка будет вставлена с теми же натуральными показателями и начисленными коэффициентами, но принимает стадийность новой сметы и соответствующие стадии сметы РПД». Вставка произвольной таблицы из системного буфера (например, из Excel) **в справке не описано**. |
| Есть ли **горячие клавиши создания раздела и текстовой строки**? | **Нет.** Ни `Ctrl+U`, ни `Ctrl+T` в справке не встречаются ни в одном модуле. Раздел и текстовая строка создаются только через меню кнопки «Создать» (разд. 6.1, стр. 1029–1032). Единственное задокументированное использование Ctrl в модуле ПРОЕКТ — мультивыбор строк в справочнике «РПД для группировки» (разд. 3.7, стр. 934). |

> **Замечание к коду:** комментарии в `pirparse/model.py` о том, что в Адепте «Ctrl+U = раздел, Ctrl+T = текстовая строка», справкой 2026.4 **не подтверждаются**. Их следует убрать или переформулировать как внутреннее соглашение парсера, а не как поведение Адепта.

### 9.2 Форматы импорта/экспорта — только модуль СМЕТА

Полный перечень форматов обмена приведён в модуле СМЕТА (страницы справки 331–336, строки `AUS_HELP.txt` 9620–9770): импорт/экспорт сметной документации в форматах обмена сметными данными с расширениями файлов, включая XML и АРПС. В модуле ПРОЕКТ аналогичного перечня нет.

**Практический вывод для разработчика:** машинный ввод данных сметы ПИР в Адепт документированными средствами модуля ПРОЕКТ невозможен. Единственные документированные пути:
1. внутренний буфер Адепта (копирование смет/разделов/расценок между сметами Адепта);
2. загрузка справочников («Должности» — Excel, «Виды деятельности», «Перечень работ» — файл неописанного формата);
3. экспорт/импорт **настроек шаблона** сметы (разд. 2.3, стр. 914);
4. вывод наружу — только печать в MS Word/MS Excel (для 2П комплексной и ГГЭ — только Excel).

Следовательно, выгрузка из нашего канона в «формат Адепта» реализуема лишь как формирование печатных форм Excel, повторяющих бланки 2П/3П/4П/сводной, либо (при наличии) как обратная инженерия внутреннего формата БД, что **в справке не описано**.
