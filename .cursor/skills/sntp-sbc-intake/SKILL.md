# Ввод СБЦ

Общий порядок папки, двух проходов и sync — в skill `sntp-book-intake`. Здесь только то, чем СБЦ отличается от НЗ. Каталог: `D:\NET\=SNTP-BOOKS`. Таблицы цен в git не коммитить.

## Паспорт

В `book.json` поле `Kind` равно `SBC`. `OrderRef` — как в ФРСН (например `СБЦП 81-2001-22`), не как в кривом обосновании сметы. Год и дата приказа берутся из источника. Если в смете другой год или дата, сверка пишет `book-ref-mismatch` и паспорт не переписывает.

`Aliases` — строки, по которым `BookReconciler.Mentions` узнаёт сборник в обосновании. Короче 3 символов псевдоним не срабатывает.

Реквизиты и статус приказа брать из Кодекс, skill `sntp-codex-search`. Таблицу цен оттуда в git не копировать.

## Таблица цены

`Tables[].Kind = "price"`. Пункт хранит `N`, название, единицу, `Xmin`/`Xmax`, `A`, `B`. `A` и `B` — тысячи рублей приказа.

- Строка без отдельных «а» и «в», только с названием, — заголовок группы, не расценка.
- Одно число в границе — точка: `Xmin` и `Xmax` равны. Пустые границы второй проход не прощает.
- «до N включительно» и следующая «от N» стыкуются. Значение ровно N относится к нижней полосе.
- Примечания под таблицей нумеруются с 1 и кончаются перед следующим крупным пунктом или словом «Таблица».

Якорь справки: `item:<таблица>/<пункт>`, иначе `table:<код>`, `general:<пункт>`, `rule:<вид>`. Фрагмент без якоря в справку не попадает.

## Форма сметы

Импорт листа 2П СБЦ — `EstimateForm.Form2PSbc` (`ExcelImporter.Parse2PSbc`). Изыскания СБЦ — `Form2PSurveySbc`. Это не форма НЗ и не карточка АСУТП.

СБЦ АСУТП 2016 — отдельная модель `AsutpModel`: баллы частей ТЗ–ПО, цепочка Ki, множитель, затем ×1000 и понижающий коэффициент к итогу. Её не раскладывать в таблицу `a`/`b`.

Коэффициент одной таблицы цены в общую переменную `FactorCatalog` не поднимать. Общая переменная — только если текст коэффициента общей таблицы содержит известный признак (среда, сероводород, стеснение, теплоизоляция).

## Чего не делать

Не воспроизводить неопубликованные таблицы «Порядка» Газпрома 2017. Не подменять справочник выгрузкой коммерческой сметы. Не писать MySQL Адепт. После `book.json` проекция только `POST /api/books/sync`.
